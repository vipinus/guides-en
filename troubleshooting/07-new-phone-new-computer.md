# 07 · After switching phones, switching computers, or reinstalling the system

## The situation

You changed devices, and what used to work fine no longer connects. This is the kind of problem support sees most often, but it almost never requires buying again or setting up the account again.

## Confirm one thing first: you do not need to buy the account again

Your subscription goes with the **account**, not with the device. Switching devices only requires reinstalling the client and re-importing the configuration on the new device. The account itself is unaffected, and its validity period does not change.

If someone tells you that switching devices requires paying again, that is not us.

## By device type

### Switching phones

1. Install the same client on the new phone (use the newest version you can)
2. Re-import the configuration — **do not** take a screenshot of the configuration on the old phone and type it in by hand; go to the website and get a fresh copy
3. It is recommended to delete or turn off the client on the old phone

Step 3 is easy to overlook: two phones connected at the same time take up two device slots.

### Switching computers

Same as above. Also note that **security software** such as 360 or Kingsoft on the new computer may block encrypted connections. The symptom is "it is installed, but it drops as soon as it connects". Turn off their network protection first and try again.

### Reinstalling the system

The configuration file is usually on the system drive and is lost on reinstall. Just get a fresh copy; there is no need to recover the old one.

### Switching routers

A router is different from other devices: there is a **binding** between it and the account. Switching to a new router requires unbinding and then binding again. For this step you need to contact us; you cannot do it yourself on the web page. See the corresponding article in the Router Guide for details.

## A very common misconception

**"I can just send the configuration file from my old phone to the new one, right?"**

In most cases you can, but there are two cases where it does not work:

- The port in the configuration is **picked at random at the moment of download**. After a long time it may no longer apply, so getting a fresh copy is safer
- Some clients' configuration format has changed after version updates, and importing an old file into a new version produces errors

So the standard practice is always: **go to the website and get a fresh copy**. It is no more trouble than transferring a file.

## What to do when the slots are full

The number of devices that can be online at the same time on one account depends on the plan: 2 for Personal, 4 for Family, 8 for Enterprise. If the old device is still connected when you switch, you may be told the limit has been reached. Three options:

- Log out or close the client on the old device
- Wait a while — idle connections are released automatically
- Temporarily upgrade the account type (the remaining time is converted at equivalent value by price), then switch back when you are done

On the web page you can see how many devices are currently online and what type each one is, and use that to work out whether you forgot to turn one off.
